# astralix Userbot

Репозиторий: [lowsense-dev/astralix на GitHub](https://github.com/lowsense-dev/astralix). Каналов и чатов проекта нет.

Из каталога проекта, после установки Python 3.10+ и uv:

```bash
uv sync --locked --inexact
.venv/bin/python -m astralix --no-git
```

При запуске зависимости не устанавливаются и не обновляются. `astralix-tl` устанавливается из [PyPI](https://pypi.org/project/astralix-tl/). Установка стороннего модуля и явно запрошенное обновление могут устанавливать зависимости через uv.

Зависимости объявлены в `pyproject.toml`, версии зафиксированы в `uv.lock`. `requirements.txt` генерируется из lock-файла для совместимости со старым updater. Дополнительные зависимости: `uv sync --locked --inexact --all-extras`.

При первом входе выбери временный Cloudflare Quick Tunnel или локальный веб-интерфейс. Для туннеля нужен `cloudflared`; одноразовая ссылка действует 15 минут, пока открыт вход. Выбор сохраняется. Изменить его можно через `--web-mode tunnel` или `--web-mode local`, а `--no-web` включает интерактивный вход в консоли.

Исходные данные Heroku автоматически не переименовываются: сохраните их резервную копию и используйте отдельный каталог данных до проверки миграции.
