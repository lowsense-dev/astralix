# astralix Userbot

Репозиторий: **radiocycle/astralix** (приватный). Каналов и чатов проекта нет.

Из каталога проекта, после установки Python 3.10+ и uv:

```bash
uv venv --python python3 .venv
uv pip install --python .venv/bin/python -r requirements.txt
.venv/bin/python -m astralix --no-git
```

При запуске зависимости не устанавливаются и не обновляются. `astralix-tl` собирается из исправленных исходников в `vendor/astralixtl-sources`. Установка стороннего модуля и явно запрошенное обновление могут устанавливать зависимости через uv.

Первый вход выполняется через консоль. Исходные данные Heroku автоматически не переименовываются: сохраните их резервную копию и используйте отдельный каталог данных до проверки миграции.
